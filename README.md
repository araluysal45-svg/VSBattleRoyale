# Storm Isle (Phase 1)
No npm install needed (zero dependencies). Requires Node 18+ and internet in the browser (Three.js loads from cdnjs).
    npm start        # http://localhost:3000   (open in 2+ tabs/devices on the same network)
    npm test         # headless 2-client integration test
Deploy: any Node host (Render/Railway/Fly/VPS) — set start command `node server.js`; PORT env is honored; WebSockets must be enabled.
